# Changelog
## v1.1.0 - The Encounter Overhaul
This update completely revamps the encounter system, offering significantly more flexibility and variety.
### 🚀 Features
*   **New Encounter System:** Replaced the basic weighted system with a powerful list-based system of "Encounter Specs". Each spec allows for fine-grained control over:
    *   **Event Type:** Ambushes, merchants, patrols, and wildlife.
    *   **Entity Groups:** Spawn multiple groups of different entities in a single encounter.
    *   **Custom NBT:** Spawn mobs with custom equipment, effects, and attributes using NBT data.
    *   **Biome Specificity:** Encounters can now be limited to specific biomes using whitelists and blacklists.
*   **Encounter Presets:** Added a vast library of over 40 pre-defined encounter presets.
*   **Configuration Rework:** The in-game configuration screen has been completely redesigned to support the new encounter system, with new sections for managing spawn entries and event types.
*   **Localization:** Full localization for all new features in Spanish, French, German, Chinese, Ukrainian, and Russian.
*   **Debug Mode:** Added a "Show event messages" option to the config for easier testing and debugging.
